# 功能评估：实例文件管理 / Web 终端（Linux）+ 一键打开实例目录（Win）

> 需求原文：Linux 版在顶部导航新开一栏（或并入日志中心）提供「终端界面」或「文件管理界面」；
> Win 版文件管理退化为「一键打开实例目录」；硬约束——权限仅限于当前用户可操作的实例目录；
> 「若评估后风险过大或难度过大则不推进，仅给出评估报告」。

## 一、现状盘点（已逐条核实）

| 项 | 结论 | 出处 |
|----|------|------|
| 顶部导航 | 现有 4 个 tab：总览 / 日志中心 / 创建 / 账号管理(adminOnly) | `web/src/App.vue:60-63` |
| 日志中心 | `web/src/pages/LogCenter.vue`（实例下拉 + WebSocket 日志流），是文件浏览的自然落点 | `ls web/src/pages/` |
| 实例归属校验 | `api/rest.py` 的 `_own(inst_id, user)` 已对 server 多用户做校验（越权/不存在 → 404） | `api/rest.py` |
| 实例目录 | 由 `instance.dir` 给出；落盘根由 `core/pathutil.py:default_install_root()` 决定（POSIX 返回 None，不覆盖 manifest 自带 install_root） | `core/pathutil.py:77` |
| 终端依赖 | `web/package.json` **无** xterm / node-pty / pyte / websocket —— 做终端需引入新依赖 | `grep` 确认 |

## 二、方案 A：Web 终端 —— 不推荐，不实现

风险：
1. **RCE 不可接受**：给任意登录用户一个 shell，等于把整台机器交出去。
2. **「仅限实例目录」无法满足**：shell 进程 `cd /` 即可逃出实例目录；所谓权限约束在终端语义下根本不成立（除非 chroot/容器隔离，远超本项目范畴）。这与需求的硬约束直接冲突。
3. **部署脆弱**：node-pty 需在 1.6GB 受限服务器上原生编译，极易失败；pyte 虽纯 Python 但仍暴露完整 shell。

**结论：违背硬约束且风险过大，本期不实现，仅作记录。**

## 三、方案 B：Web 文件管理器 —— 推荐，可落地

形态（建议并入「日志中心」或新增「实例文件」tab）：
- 目录树/列表浏览（仅 `instance.dir` 之下）
- 文本文件查看、下载
- 受限写入：仅允许在实例目录内新建/上传/编辑；**禁用**越界删除、禁用执行
- 路径穿越防护：`os.path.realpath` 后必须仍以 `instance.dir` 为前缀，否则 403

权限设计（复用既有，零新增权限逻辑）：
- 每个端点先 `_own(inst_id, user)` 再过 `instance.dir` 前缀 containment
- server 多用户天然只能看到自己的实例目录

风险评估：
- **中低**：纯 Python 路径操作 + 现有 fetch/WS，**无新原生依赖**
- 主要风险点：① 路径穿越（必须 realpath 前缀校验）② 大文件下载（流式 + 大小上限）③ 写权限粒度（~~建议先只读~~ → **用户已拍板带受限写**，见第五节）

## 四、方案 C：Win 一键打开实例目录 —— trivial

`os.startfile(instance.dir)`（Win）/ `xdg-open`（Linux 桌面）。仅本地单机，权限无虞。
建议作为 Linux 文件管理器的「在文件管理器打开」按钮，在 Win 构建里退化为直接打开。

## 五、结论与用户拍板结果

1. **不做 Web 终端**（风险过大、且无法满足"仅限实例目录"）。
2. **做方案 B 文件管理器**（Linux），Win 保持方案 C 一键打开。

### 实现要点（已合入）

- 文件系统逻辑集中在 `core/instance_files.py`（纯逻辑、便于单测）：
  realpath 前缀 containment（`../` / 绝对路径 / 软链逃逸一律 `PermissionError`）、
  读上限 4MB、写上限 16MB、原子写（临时文件 + replace）、禁止删除实例根。
- `api/rest.py` 只做 `_own` 归属校验 + HTTP 映射 + 错误码转换；7 个端点
  （list / content / download / write / mkdir / rename / delete）**注册在 `{op}` 通配之前**。
- 前端 `api.js` 补齐 4 个写操作函数；`LogCenter.vue` 文件视图加编辑保存 / 上传 /
  新建 / 重命名 / 删除（重命名与删除走 `prompt`/`confirm`，删除有二次确认）。
